# 娯楽時間管理アプリ

1週間の娯楽時間を管理するWebアプリケーションです。

## 機能

- **週間目標設定**: 1週間に使える娯楽時間を設定
- **タイマー機能**: 娯楽時間の計測（開始・停止・リセット）
- **進捗表示**: 使用時間、残り時間、使用率を視覚的に表示
- **履歴管理**: 過去の記録を確認
- **自動週リセット**: 毎週月曜日に自動的にリセット
- **データ永続化**: ブラウザのLocalStorageにデータを保存

## 使い方

### 1. 目標時間の設定

「週間目標設定」セクションで1週間に使える娯楽時間（時間単位）を入力し、「保存」ボタンをクリックします。

### 2. 娯楽時間の記録

1. 娯楽を始めるときに「開始」ボタンをクリック
2. 娯楽を終えたら「停止」ボタンをクリック
3. 自動的に使用時間が記録され、履歴に追加されます

### 3. 進捗確認

- **目標時間**: 設定した週間目標
- **使用時間**: 今週使った娯楽時間
- **残り時間**: 今週残っている娯楽時間
- プログレスバーで視覚的に確認できます

### 4. その他の機能

- **履歴をクリア**: 履歴のみを削除（使用時間はそのまま）
- **週データをリセット**: すべてのデータをリセット
- **タイマーリセット**: 現在のタイマーをリセット（記録せずに中断）

## GitHub Pagesでの公開方法

### 1. リポジトリの設定

1. GitHubでリポジトリを作成
2. コードをpush

```bash
git add .
git commit -m "Initial commit"
git push origin main
```

### 2. GitHub Pagesの有効化

1. GitHubリポジトリページで「Settings」タブを開く
2. 左メニューから「Pages」を選択
3. 「Source」で「Deploy from a branch」を選択
4. 「Branch」で「main」ブランチと「/ (root)」を選択
5. 「Save」ボタンをクリック

数分後、`https://clayAndromeda.github.io/TimeBudget/` でアクセスできるようになります。

## ブラウザ対応

モダンブラウザ（Chrome、Firefox、Safari、Edge）の最新版に対応しています。

## データについて

- すべてのデータはブラウザのLocalStorageに保存されます
- ブラウザのデータを削除すると記録も消えます
- 別のブラウザやデバイスでは別のデータとして管理されます
